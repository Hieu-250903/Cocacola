# 🥤 Coca-Cola Interactive Showcase

A premium, interactive web application celebrating Coca-Cola products. This landing page features high-fidelity visual layouts, modern typography, fluid custom animations, and responsive page routing.

## 🚀 Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **React 19** | Dynamic view rendering and state management |
| **Vite** | Modern, ultra-fast frontend build tooling |
| **TypeScript** | Static typing and enhanced developer tooling |
| **React Router v7** | Fluid client-side routing between showcase pages |
| **Lucide React** | Premium icon library for layout and controls |
| **Vanilla CSS** | Custom animations, custom scroll-driven bottle effects, and premium transitions |

## ✨ Features

- **Home Showcase**: High-fidelity landing experience with dynamic bubbles and fluid typography.
- **Scroll Coke Bottle Effect**: Unique visual interactive section where scrolling reveals Coca-Cola pouring details.
- **Discover Section**: Curated exploration of the product range with rich descriptions and layouts.
- **Brands Explorer**: Overview of diverse Coca-Cola family brands (Coca-Cola Zero, Sprite, Nutriboost, Monster).
- **Fully Responsive**: Crafted to look exceptional across mobile, tablet, and desktop screens.

## 🛠️ Getting Started

### Prerequisites
- **Node.js** (LTS version recommended, v18+)
- **npm** (v9+)

### Installation
Clone the repository and install dependencies:
```bash
# Clone the repository
git clone <your-repository-url>
cd Cocacola

# Install packages
npm install
```

### Development
Launch the interactive dev server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
Compile and bundle production-ready assets:
```bash
npm run build
```
Preview the built package locally:
```bash
npm run preview
```
